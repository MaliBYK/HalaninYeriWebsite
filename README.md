# Hala'nın Yeri Camping

Olympos, Antalya'da portakal ağaçları altında kamp deneyimi sunan Hala'nın Yeri Camping için tek sayfalık tanıtım sitesi.

## Teknolojiler

- React 19 + Vite
- Tailwind CSS v3
- Saf CSS animasyonları (framer-motion kullanılmadı)

## Geliştirme

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```
